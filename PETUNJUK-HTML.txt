INFOTRINK — PAKET SUMBER UNTUK EKSPOR HTML

PENTING:
- Berkas sumber dari arsip yang dikirim dipertahankan apa adanya.
- Tidak ada desain, isi halaman, CSS, komponen, gambar, atau struktur sumber yang diedit.
- File konfigurasi Next.js pada proyek ini sudah mengaktifkan output: "export".
- Folder HTML hasil build (out/) belum dapat dibuat di lingkungan ini karena proses pemasangan dependensi npm tidak selesai.

CARA MEMBUAT HTML STATIS:
1. Pasang Node.js versi 20 atau lebih baru.
2. Buka terminal pada folder proyek (folder yang berisi package.json).
3. Jalankan: npm install
4. Setelah selesai, jalankan: npm run build
5. Jika build berhasil, hasil HTML statis berada di folder out/.
6. Buka out/index.html atau unggah seluruh isi folder out/ ke hosting statis.

CATATAN:
Folder proyek ini adalah salinan kerja terpisah. Arsip asli yang Anda unggah tidak diubah.
